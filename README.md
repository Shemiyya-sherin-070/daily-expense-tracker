# Daily Expense Tracker

A simple desktop application built with Python and Tkinter to track daily expenses efficiently.

## Features
- Add expenses for a specific date selected from the calendar
- Update existing expenses
- Delete expenses
- View expenses recorded for any selected date
- View the total expense for the selected date
- Categorize expenses using a dropdown list

## Tech Stack
- Python
- Tkinter
- CSV (Data Storage)

## How It Works
The application allows users to:
1. Choose a date from the calendar
2. Add expense details with category selection
3. View all expenses and the total spending for the selected date
4. Edit or remove saved expenses

## Data Storage
All expense records are stored locally in a CSV file.

## Installation
Clone the repository:

```bash
git clone https://github.com/Shemiyya-sherin-070/daily-expense-tracker.git
cd daily-expense-tracker
```

Run the application:

```bash
py backend.py
py frontend.py
py main.py
```
